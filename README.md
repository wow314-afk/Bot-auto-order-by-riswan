# 🤖 ZYRIX PLP PROJECT - Telegram Bot

Bot Telegram untuk jualan produk digital (MEMBER, RESS, OWNER, BASE) dengan pembayaran via DANA/QRIS.

## 📌 Fitur

- Menu Start dengan gambar custom
- 4 Produk: MEMBER 3K, RESS 7K, OWNER 9K, BASE 10K
- Pembayaran QRIS DANA + Transfer Manual
- Kirim bukti TF otomatis ke owner
- Verifikasi dengan tombol (✅/❌)
- BASE aman (kirim file langsung via bot)
- Channel orderan otomatis
- Wajib join channel sebelum order
- Broadcast ke semua user
- Maintenance mode (admin tidur)
- GC (Group Chat) untuk diskusi

## 📱 Command

### User
- `/start` - Menu utama
- `/price` - Daftar harga
- `/help` - Bantuan

### Owner
- `/maintenance` - Aktifkan maintenance
- `/offmaintenance` - Matikan maintenance
- `/status` - Cek status
- `/broadcast [pesan]` - Kirim ke semua user
- `/bc` - Panduan broadcast
- `/users` - Lihat user
- `/orders` - Lihat order
